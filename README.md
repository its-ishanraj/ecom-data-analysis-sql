# 🛒 Zepto SQL Data Analysis
## Project Overview

This project analyzes Zepto's product inventory using MySQL to answer real-world business questions. It includes database creation, data cleaning, exploration, and business insights generated through SQL queries.

---

## Dataset

- Product Inventory Data from **kaggle**
- CSV Format
- Imported into MySQL

---

## Skills Used

- SQL
- Data Cleaning
- Data Exploration
- Aggregations
- GROUP BY
- HAVING
- ORDER BY
- CASE WHEN
- COUNT
- SUM
- AVG
- Business Analysis

---

## Project Workflow

1. Database Creation
2. Table Creation
3. Data Import
4. Data Exploration
5. Data Cleaning
6. Business Insights

---

## Business Questions Answered

- Top 10 best value products based on discount percentage
- Products with high MRP but out of stock
- Estimated revenue by category
- Products with MRP > 500 and discount < 10%
- Top 5 categories with highest average discount
- Price per gram for products above 100g
- Product segmentation by weight
- Total inventory weight by category
